# mazgo — الموقع التعريفي

موقع تعريفي ثابت (static) لتطبيق mazgo: منصة فنلندية تربط المطاعم والمخابز ومحلات الأغذية
بالزبائن لبيع فائض الطعام اليومي بخصم لا يقل عن 30 %.

بنية HTML/CSS/JS خام بدون أي build step — يُنشر كما هو على أي استضافة static.

## اللغات

ثلاث لغات كاملة بمبدّل في الترويسة، والافتراضي الفنلندي:

- **fi** — الفنلندية (الافتراضية)
- **en** — الإنجليزية
- **ar** — العربية مع اتجاه RTL كامل

الترجمات كلها في `i18n.js` (مفاتيح `data-i18n` في HTML). اللغة تُحفظ بـ localStorage
(المفتاح `mazgo-lang`)، ويمكن فرضها برابط: `?lang=ar`.

## الصفحات

| الصفحة | الوصف |
|---|---|
| `index.html` | الرئيسية: كيف يعمل، التأثير، شاشات التطبيق، تواصل |
| `pricing.html` | الأسعار والعمولة (20 %) والتسوية الأسبوعية |
| `help.html` | الأسئلة الشائعة للزبائن والتجار |
| `blog.html` | المدونة |
| `blog-finland-food-waste.html` | لماذا تهدر فنلندا الطعام؟ |
| `blog-global-food-waste-numbers.html` | أرقام الهدر الغذائي عالمياً |
| `blog-best-before-dates.html` | تواريخ «أفضل قبل» وما تعنيه |
| `terms.html` / `privacy.html` | الشروط والخصوصية — **مسودات تحتاج مراجعة محامٍ** |
| `delete-account.html` | طلب حذف الحساب (متطلب متاجر التطبيقات) |

الصفحات الثمانية ما عدا `index.html` بُنيت بسكربت `_build_pages.py`
(موجود في هذا المجلد — عدّل فيه ثم أعد التوليد عند تغيير قالب صفحات فرعية).

- الخلفية كريمية `#F7F6F3`، الأساسي قرمزي `#E23744`، النصوص والأقسام الداكنة
  كحلي `#131A3D`، العنبري `#F5A623` إكسسوار فقط.
- الخطوط: **El Messiri** للعناوين و **IBM Plex Sans Arabic** للنصوص — نفس خطوط التطبيق.
- الأصول في `assets/brand/` (الشعارات) و `assets/screens/` (لقطات) و `assets/blog/` (صور المدونة).

## النشر على Cloudflare Workers

نفس طريقة نشر موقع «اتمشى». إما إضافة route لنفس الـ Worker الحالي مع تغيير
`directory` في `wrangler.jsonc`:

```jsonc
{
  "name": "itmasha-website",
  "assets": { "directory": "./mazgo-website" }
}
```

أو Worker جديد مخصص:

```bash
npx wrangler deploy --name=mazgo-website --assets=mazgo-website
```

## ملاحظات قبل الإطلاق

1. **الشروط والخصوصية وشروط المتجر (`terms.html`، `privacy.html`) مسودات عامة** —
   لا تُنشر نهائياً قبل مراجعة محامٍ فنلندي (متطلبات GDPR/EVKL وقانون حماية المستهلك).
2. روابط «حمّل التطبيق» وأيقونات المتاجر placeholder — تُحدَّث حين يصدر التطبيق بمتاجر App Store / Google Play.
3. بيانات التواصل (`yhteys@mazgo.fi`، الهاتف) وروابط الشبكات الاجتماعية placeholder — حدّثها في `i18n.js`.
4. لقطة `assets/screens/screen-feed.jpg` مؤقتة من جلسات اختبار RTL القديمة وفيها نصوص عربية —
   تُستبدل بلقطات نظيفة من المحاكي بواجهة فنلندية (DEMO mode) قبل الإطلاق.
5. قسم الإحصائيات في الرئيسية معنون «أهداف السنة الأولى» عمداً — لا يدّعي إنجازات حقيقية.
